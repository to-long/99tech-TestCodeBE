# Problem 1

Provide three unique JavaScript implementations of `sum_to_n`.

## Implementations

- `sumToNFormula(n)` uses the arithmetic series formula.
- `sumToNLoop(n)` uses an iterative loop.
- `sumToNRecursive(n)` uses recursion.

## Run From CLI

Go to the `Problem1` directory:

```sh
cd Problem1
```

Run with npm:

```sh
npm start -- formula 5
npm start -- loop 5
npm start -- recursive 5
```

Expected output:

```sh
15
```
